🔗 Featured Project — QUERA:

As part of my Developer journey, I’m developing QUERA using Python, Flask, REST APIs, and SQLite.

The application converts a long URL into a short, shareable link. When a user submits a URL, the backend generates a unique short code, stores the URL mapping in the database, and provides a shortened URL. 🔐

When the shortened URL is accessed, the Flask backend looks up the corresponding original URL and automatically redirects the user to it. ↗️

Core concepts:

🔗 REST API → 🌐 Flask Routing → 📡 HTTP Requests → 🗃️ SQLite → 🔐 Unique Code Generation → ✅ URL Validation → ↗️ HTTP Redirects
